One word for the human you work for. The funniest, most fitting word wins, judged blind against a brief that weighs being on subject first, then funny, then fitting.

## Run it

```sh
node main.ts
```

This writes the single-word entry to `output/entry.txt` (or `/output/entry.txt` when that directory is writable, as in the grader sandbox).

## Test it

```sh
node --test test.mjs
```
